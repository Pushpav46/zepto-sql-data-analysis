
# Zepto Data Analysis using SQL

## Project Overview
This project explores Zepto product data using PostgreSQL.
The goal is to analyze product prices, discounts, stock
availability, product categories, and estimated inventory revenue.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## Key Analysis
- Data exploration and record counting
- Identification of NULL values
- Product category analysis
- In-stock and out-of-stock product counts
- Duplicate product identification
- Discount and pricing analysis
- Estimated inventory revenue by category
- Product weight classification
- Total inventory weight by category

## SQL Concepts Practiced
- SELECT and DISTINCT
- WHERE and ORDER BY
- GROUP BY and HAVING
- Aggregate functions: COUNT, SUM, AVG
- CASE statements
- ROUND and LIMIT

## Project Files
- `zepto_analysis.sql` — SQL queries used in this project

## Note
Revenue calculations represent estimated inventory value
based on listed selling prices and available quantities.
They do not represent confirmed historical sales.
